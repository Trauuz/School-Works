# Campus Companion - MAD2 Laboratory Exercise 1

This Storyboard-based UIKit project completes the required welcome screen:

- Bold 28 pt title: **Campus Companion**
- 16 pt subtitle: **Your Campus, In Your Pocket**
- 150 x 150 aspect-fit image view, centered in the safe area
- **Get Started** button that changes the subtitle to **Let's get started!**
- Auto Layout constraints matching the laboratory handout

## Open and run on a Mac

1. Extract this folder and open `CampusCompanion.xcodeproj` in Xcode.
2. If Xcode asks to update project settings, accept the recommended settings.
3. Choose an iPhone simulator, such as **iPhone SE (3rd generation)**, then press `Cmd + R`.
4. Run again with **iPhone 15 Pro Max** to verify the responsive layout.

Xcode and the iOS Simulator require macOS, so final build verification must be done on a Mac.
